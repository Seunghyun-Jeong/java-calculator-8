# java-calculator-precourse

## 기능

- **기본 구분자 :** 쉼표(`,`)와 콜론(`:`)을 사용하여 숫자들을 구분
- **커스텀 구분자 :** 입력 문자열이 `//<구분자>\n<숫자열>` 형태일 경우, `<구분자>`를 숫자 구분자로 사용 (예: `//;\n1;2;3` -> 세미콜론 `;`)
- **숫자 추출 및 합산 :** 구분자를 기준으로 숫자를 분리하여 합산
- **입력 검증 :** 숫자와 허용된 구분자만 포함되어야 하며, 잘못된 입력은 예외 메시지 출력 후 다시 입력을 받음

---

## 사용 방법

1. 프로그램을 실행하면 `덧셈할 문자열을 입력해 주세요.` 메시지가 표시됩니다.
2. 숫자들과 구분자(기본 구분자: `,` 또는 `:` 또는 커스텀 구분자)를 포함한 문자열을 입력합니다.

---

## 입력 예시

- 기본 구분자 사용 (쉼표 `,`, 콜론 `:`)
  
  1,2:3


- 커스텀 구분자 사용 (세미콜론 `;`)
  
  1;2;3

결과 : 6
